全书地图 · The Big Picture

这本书,是一条因果链

全书 8 章不是 8 个孤立话题,而是一条从"力从哪来"一路走到"人怎么把车开稳"的链子。先看清这条链,再学每一课,就永远不会迷路。

第 3 章 车辆的运动性能:把上面这台车放进各种工况(转弯/侧风/乘坐/驱动制动/极限)去评价与解析。

一句话总纲:轮胎是唯一力源,力受摩擦圆约束 → 前后/左右怎么分配这些力,决定车的横摆与侧移响应(二自由度模型)→ 转向、悬架、4WS、驱动/制动控制都只是调节这个响应的旋钮 → 最后把车交给"人",在人—车闭环里检验稳定性。前 7 章造车,第 8 章把车交给人。

02全书真实目录(8 章)

页码为原书印刷页码。本书没有单独的"绪论"章(开篇即第 1 章轮胎),也没有单独的"空气动力学"章(侧风稳定性见 3.3.1)。

第 1 章 轮胎特性 p1

  • 1.1 影响运动性能的轮胎特性(坐标系 / 尺寸 / 刚度 / 线性区 / 非线性区 / 主观评价)
  • 1.2 解析用轮胎模型　1.3 模型案例:Magic Formula　1.4 轮胎特性测量技术

第 2 章 车辆的运动性能理论 p21

  • 2.1 运动与运动方程式(平面 / 含转向系 / 含侧倾 / 垂向)
  • 2.2 平面 2 自由度模型的线性分析(匀速环行 / 瞬态响应 / 外部干扰 / 柔性偏向 / 复合侧抗刚度)
  • 2.3 非线性区域分析方法(线性化 / 环行几何学 / 横摆力矩法 / 状态平面)

第 3 章 车辆的运动性能 p39

  • 3.1 评价与解析(参数测量 / 道路试验 / 室内试验 / 仿真)
  • 3.2 转向时　3.3 外部干扰(侧风稳定性 / 乘坐舒适性 / 路面干扰)　3.4 驱动制动时　3.5 极限附近

第 4 章 转向系统与车辆运动性能 p65

  • 转向响应/反作用力 · 动力转向 · 转向几何学(阿克曼、主销) · 跑偏 · 转向角/力控制

第 5 章 悬架与车辆的运动性能 p76

  • 功能 · 悬架特性与操稳(束角/接地点/外倾/侧倾/加减速姿态) · 乘坐舒适性 · 类型 · 主动悬架

第 6 章 4WS 系统与车辆运动性能 p104

  • 目的与原理 · 运动学理论 · 控制分类 · 实际控制(横摆率延迟改进、车身零侧偏、理想转向响应) · 各种结构

第 7 章 驱动力及制动力控制与车辆运动性能 p121

  • 控制定位与目标 · 前后分配 · 左右分配(DYC)、扩展动态四边形 · 纵向力与侧向力综合控制(与 4WS 综合)

第 8 章 人—车系统的运动 p146

  • 前言 · 人的控制动作 · 操纵动作模型(传递函数 / 预瞄控制 / 专家系统) · 人与汽车的稳定性
