# 🗺️ 全书框架与地图

## 一、这本书到底在讲什么

全书 8 章不是 8 个孤立话题,而是**一条因果链**,从"力从哪来"一路走到"人怎么把车开稳":

```
        ┌──────────────────── 环境:路面 μ、空气/侧风 ────────────────────┐
        │                                                                  │
   [力从哪来]         [车怎么响应]              [用什么调这个响应]        [谁来闭环]
   第1章 轮胎     →   第2章 运动性能理论   →   第4章 转向系统            →  第8章
   ·侧偏角→侧向力      ·平面二自由度模型         第5章 悬架                   人—车系统
   ·摩擦圆(纵/侧       ·匀速环行:US/OS/NS       第6章 4WS                    ·驾驶人模型
     力互相抢)         ·稳定性因子              第7章 驱动/制动力控制、DYC     ·预瞄
                       ·瞬态响应/非线性          (本质都在"重新分配"轮胎力)     ·人车稳定性
                                                                              │
              第3章 车辆的运动性能:把上面的车放到各种工况下评价与解析          │
        │     (评价方法 / 转弯 / 侧风 / 乘坐 / 驱动制动 / 极限)              │
        └──────────────────────────────────────────────────────────────────┘
```

**一句话总纲**:轮胎是唯一力源,力受摩擦圆约束 → 前后/左右怎么分配这些力,决定车的横摆与侧移响应(二自由度模型)→ 转向、悬架、4WS、驱动/制动控制都只是调节这个响应的旋钮 → 最后把车交给"人",在人—车闭环里检验稳定性。**前 7 章造车,第 8 章把车交给人。**

## 二、全书真实目录(8 章)

> 页码为原书印刷页码。本书**没有单独的"绪论"章**(开篇即第 1 章轮胎),也**没有单独的"空气动力学"章**(侧风稳定性见 3.3.1)。

### 第 1 章 轮胎特性(p1)
- 1.1 影响车辆运动性能的轮胎特性(坐标系 / 尺寸 / 刚度 / 线性区 / 非线性区 / 主观评价)
- 1.2 解析运动性能用轮胎模型
- 1.3 模型案例分析:Magic Formula
- 1.4 轮胎特性测量技术

### 第 2 章 车辆的运动性能理论(p21)
- 2.1 汽车的运动与运动方程式(平面运动 / 含转向系 / 含侧倾 / 垂向)
- 2.2 利用平面 2 自由度模型的线性分析(匀速环行 / 瞬态响应 / 外部干扰 / 柔性偏向 / 复合侧抗刚度 / 驱动制动准匀速环行)
- 2.3 非线性区域车辆运动分析方法(线性化 / 环行几何学 / **横摆力矩法** / 状态平面)

### 第 3 章 车辆的运动性能(p39)
- 3.1 运动性能的评价与解析(车辆参数测量 / 道路试验 / 室内试验 / 仿真)
- 3.2 转向时的运动性能(稳态 / 动态响应 / 侧倾姿态 / 转向力)
- 3.3 外部干扰时的运动性能(**侧风稳定性** / 乘坐舒适性 / 路面干扰)
- 3.4 驱动、制动时的运动性能
- 3.5 极限附近的运动性能(转弯/转向极限 / 低摩擦路面)

### 第 4 章 转向系统与车辆运动性能(p65)
- 4.1 转向响应/转向反作用力 · 4.2 动力转向 · 4.3 转向几何学(阿克曼、主销) · 4.4 跑偏等 · 4.5 转向角/力控制

### 第 5 章 悬架与车辆的运动性能(p76)
- 5.1 功能 · 5.2 悬架特性与操纵稳定性(束角/接地点/外倾/侧倾/加减速姿态) · 5.3 乘坐舒适性 · 5.4 类型与特性 · 5.5 主动悬架

### 第 6 章 4WS 系统与车辆运动性能(p104)
- 6.1 目的与原理(前馈/反馈/低速小转弯) · 6.2 运动学理论 · 6.3 控制分类 · 6.4 实际控制(横摆率延迟改进、车身零侧偏、理想转向响应、非线性区、协调控制) · 6.5 各种结构 · 6.6 展望

### 第 7 章 驱动力及制动力控制与车辆运动性能(p121)
- 7.1 控制定位与目标 · 7.2 前后分配控制 · 7.3 **左右分配控制(DYC)**、扩展动态四边形 · 7.4 纵向力与侧向力综合控制(与 4WS 综合、DYC+4WS) · 7.5 展望
- 署名:礒田桂司

### 第 8 章 人—车系统的运动(p146)
- 8.1 前言 · 8.2 人的控制动作 · 8.3 操纵动作模型(传递函数 / **预瞄控制** / 专家系统 / 其他) · 8.4 人与汽车的稳定性
- 署名:景山一郎

## 三、逻辑主线 ↔ 真实章节 对照

| 逻辑环节 | 对应章 |
|---|---|
| 力从哪来(唯一力源、摩擦圆) | 第 1 章 |
| 车如何响应(二自由度、US/OS、稳定性因子、瞬态/非线性) | 第 2 章 |
| 把车放进各种工况评价(转弯/侧风/乘坐/驱动制动/极限) | 第 3 章 |
| 调节响应的旋钮 | 第 4 章(转向)、第 5 章(悬架)、第 6 章(4WS)、第 7 章(驱动/制动、DYC) |
| 人进入闭环(可控性、稳定性) | 第 8 章 |
