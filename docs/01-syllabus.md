# 🎓 课程表与教学方法

## 一、我作为老师的核心方法

一个只会开车的人,已经有一整套**身体经验**——过弯发飘、急刹点头、高速变道心里发慌。教学原则:

1. **每节课从你开车时的一个真实感觉切入**(钩子),再用书里的概念告诉你"你感觉到的那个东西,书里叫什么、为什么"。
2. **严格只用书里的内容**。书里没有的会明说"这本书没讲",绝不用外部说法糊弄。
3. **看图学**。抽象概念一律配书里的原图(以"图 X-Y"编号引用并文字复述)。
4. **层层搭台**。后一课一定用到前一课的结论,绝不跳。
5. **每课结尾留一个"开车验证题"**:下次开车去体会某个现象,回来对答案。
