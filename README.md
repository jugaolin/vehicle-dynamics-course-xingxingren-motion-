## 🧭 一句话总纲

> 轮胎是唯一的力源(受**摩擦圆**约束)→ 前后/左右怎么**分配这些力**,决定了车的横摆与侧移响应(**二自由度模型**)→ 转向、悬架、4WS、驱动/制动控制都只是**调节这个响应的旋钮** → 最后必须把车交给"人",在**人—车闭环**里检验能不能开得稳。**前 7 章造车,第 8 章把车交给人。**
