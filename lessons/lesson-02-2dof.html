你可能坐过两种车:一种进弯"稳、往外推",越快越要多打方向;另一种"贼灵、爱甩尾",快了心里发慌。为什么同样四条胎,车的脾气差这么多?这一课给你答案——而且答案是一个可以算出来的数。

01先把四个轮子简化成"一台自行车"

整车四个轮子太复杂。书里(2.1.1 节)先做一个关键简化:忽略车身的高度、侧倾、俯仰,把整台车拍扁在地面上,看成一个平面里的刚体。这样,车的运动就只剩两个有意义的自由度:

  • 侧移——整台车往侧向平移(质心横向动);
  • 横摆——车头绕竖轴转(转多快叫横摆角速度 r)。

这就是平面二自由度模型(书·图 2-1),全书后面所有"车怎么响应"的分析都建在它上面。前后两条胎一简化,画出来就像一台自行车:

02定速定舵转圈:决定脾气的那"一个数"

怎么量一台车的脾气?书里(2.2.1 节)用最朴素的办法:用固定的方向盘角度、固定的车速,让车匀速转圈(匀速环行),看会转出多大的横摆角速度。算出来是这样(式 2-20):

r = [ 1 / (1 + K·V2) ] · (V / l) · δf

式子长,但只要盯住那个 K。它就是决定一切的稳定系数(式 2-23),由车的质量、轴距、质心位置和前后轮侧抗刚度算出:

K = ?( m / 2l2 ) · ( l_f·K_f ? l_r·K_r ) / ( K_f·K_r )

你不用会算它。只要知道:一台车造好后,K 就基本定了,是正、是负、还是零,决定了它的全部转向脾气。

直觉版

K 本质在问一句话:前轴和后轴,谁先"给不动"(先到上一课说的抓地极限)?后轴相对更弱 → 尾巴先滑;前轴相对更弱 → 车头先推。K 就是把这件事压缩成的一个数。

03三种脾气:不足 / 中性 / 过度转向

书里(式 2-23 下方)把 K 的正负直接命名成三种转向特性——这就是你天天听说的那些词的正式名字:

  • K > 0 → 不足转向(US, Understeer):车速越高,想转同样的弯,方向要打得越多。俗称"推头"。
  • K = 0 → 中性转向(NS, Neutral):方向盘角度和车速无关,始终一个量。
  • K < 0 → 过度转向(OS, Oversteer):车速越高,方向反而要回一点,否则转过头。俗称"甩尾"。

04为什么车都被设计成"不足转向"?

看图 2-5 里那条 OS 虚线冲向 Vc——这就是关键。书里(式 2-24)给出:过度转向的车存在一个临界车速

Vc = √( ?1 / K )　　(仅当 K < 0,即 OS 时存在)

书里明说:过度转向时,车速一旦超过这个 Vc,车辆运动就变得不稳定(2.2.2 节:此时瞬态响应的 ω?2 变负)。也就是说,OS 的车开快了会自己发散、失控。而不足转向(US)没有这个临界速度——所以量产车基本都设计成 US:牺牲一点灵活,换来"越快越稳、可控"。

那 US / OS 到底由什么决定?书里给了一个更好懂的几何解释。

书里(2.2.3 节)定义了一个点叫中性转向点 NSP,再定义静态余量 SM(式 2-37)——质心到 NSP 的相对位置:

SM = ?( l_f·K_f ? l_r·K_r ) / ( l·(K_f + K_r) )
  • 质心在 NSP 之前(更靠车头)→ SM 为正 → 不足转向;
  • 质心与 NSP 重合 → 中性转向;
  • 质心在 NSP 之后(更靠车尾)→ 过度转向。

一课一收:你现在能说的三句话

  1. 整台车转弯,可以简化成一台"自行车"(平面二自由度),只做两件事:侧移 + 横摆;
  2. 一台车的转向脾气,压缩成一个稳定系数 K:K>0 不足转向(推头)、K=0 中性、K<0 过度转向(甩尾);
  3. 过度转向的车有个临界车速,超过就失控;所以车基本都设计成不足转向——本质是让质心落在中性转向点之前。
?? 开车验证题

在安全空旷的场地里绕一个固定大小的圆,保持圆不变,慢慢把车速提上去,留意方向盘要不要越打越多。如果越快越得加方向——恭喜,你的车是不足转向,也就是绝大多数家用车的脾气。(注意:全程低速、留足余量,别去试临界。)
